## Capture Checklist

- Use the same device size ratio for all screenshots.
- Keep language consistent (English UI copy).
- Remove personal identifiers and sensitive data.
- Keep status bars and system notifications clean.
- Use stable sample data so labels and values are readable.
- Avoid motion states (loading spinners) unless explaining loading behavior.

## Layout in Word
